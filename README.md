# Reol 2

以 Windows 单机第三人称 3D 体素沙盒为出发点，探索 Reol 的修仙世界和不同身份的生活。

项目使用 Unity 6.3 LTS（`6000.3.29f1`）、URP 和 C#。首个 Demo 验证第三人称走坡、跨区块移动和按格挖填。
