# Reol 2 设计方向

Reol 2 是 Windows 单机第三人称 3D 修仙沙盒。玩家以世界中一个生命的身份探索、成长，并通过自己的行动影响所处的地方。世界感来自无缝的旅行、可改造的自然地形，以及离开后仍会发生的变化。

## 世界与角色

- 玩家可在附近步行或飞行，远距传送允许准备目的地。地表、山崖与洞穴呈现连续形状，挖填能改变实际地形。
- 长期方向是让居民、门派、聚落和时代变化拥有可观察的因果。玩家回访时可以看到人、物资或组织的变化，也能通过自己的行动参与。
- 不同身份对应不同的生活方式，例如凡人经营、散修游历与组织管理。长期希望角色能够在死亡后于同一个世界开始另一段人生。
- 视觉采用统一的低多边形方向，优先可程序化生成的地貌和可复用素材。第三人称自由动作是战斗方向，具体操作随可玩样例验证。

当前原型集中验证移动、流送和可编辑地形。玩法完成范围以试玩说明和系统状态为准。人员、内容和工程规模用实际完成成本与同机证据校准。[项目现状](README.md) · [系统状态](roadmap/README.md)
