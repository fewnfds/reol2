# 大世界视觉、自然系统与主角

2026 年 11 月 22 日 · Unity 6000.3.29f1、Windows、URP。构建和复现入口见[随机大世界试玩与实测](../large-world-demo.md)。

## 试玩路线

从海岸向内陆走，低头看沙土变化，再按 F7 从高空看山脉。按 F1 潜水，按 F2 进入巨洞，对照水上、水下、洞口和深处岩色。按 `]` 可前进三个游戏小时。准星瞄着可编辑地表或洞壁时按 G，可读取岩层、露矿或附近矿迹。Alt 慢走、Shift 快跑、Space 跳跃、按住 C 下蹲。F 切换调试飞行，水中和飞行时 Space/C 控制升降。

## 地表与水面

- 近处体素、地表远景和巨洞代理共用配色。大世界顶点色采用全球坐标上的 4,096 米与 256 米两档不规则变化。远景采样变粗时逐步减弱较细频带。岩土、沙岸和高山雪线由高度、坡度与深度混合。近处每个混合页备好两档色块的四角值，顶点只做页内插值。[配色规则](../../Assets/Reol2/World/WorldMaterial.cs)
- 8 米尺度的近处细节随视距和像素覆盖面积衰减。海、湖和河表面用低对比度的 128 米不规则扰动和基于视角的天光反射色。整数格锚点与局部浮点坐标分开，浮动原点移动后使用相同的全局位置。洞口覆盖裁切和地形碰撞走已有路径。[地形着色](../../Assets/Reol2/Visuals/VoxelSurface.shader) · [水面着色](../../Assets/Reol2/World/ContinentOcean.shader)

## 主角

主角用 Quaternius 免费 Standard 版人体骨架与 12 条原地动作，衣、袖口、腰带和靴采用项目配色。Unity Humanoid 重定向动作，Animator 的 1D Blend Tree 按碰撞后的实际速度混合待机、慢走、跑和冲刺。下蹲、起跳、腾空、落地、游泳分别有动作，飞行暂以施法悬浮姿态表现。

按同一角色骨架采样完整动作周期，慢走、跑步、冲刺的肩线平均偏航分别为 7.5°、27.4°、19.7°。按动作校准导入旋转后，三个周期的肩线和髋线平均偏差绝对值均小于 1°。角色的移动方向和物理根节点朝向保持一致。默认跑步与冲刺仍为 4.8 和 9 米/秒，慢走与蹲行调整到 1.25 和 0.9 米/秒，同步校准四档播放速率。

角色用现有 CharacterController 接受流送限幅和碰撞。跳起撞顶终止上升，低顶下保持蹲姿。OnAnimatorIK 在着地、速度允许时用两条局部射线调整脚面，腾空和游泳时退出。坡和低台阶的物理通行沿用胶囊体的坡度与步高。[动画驱动](../../Assets/Reol2/World/PlayerAnimatorDriver.cs) · [来源与许可](../../THIRD_PARTY_NOTICES.md)

## 顾问复核

材质、自然系统和角色各做一轮 Neon 双路咨询，随后附实际改动源码做实现复审。采用整数原点分离、限制可见频带、按时空插值天气、勘探核实实岩、真实位移驱动、起身净空和撞顶检查。已有场景将玩家根设置为忽略射线，起身和远传用 Play Mode 验证。当前环境与勘探查询量较小，直接求值即可复现。原始咨询和运行证据在 Git 忽略的本机目录 `.local/research/world-expansion-2026-11-22/`。

第五轮双路复审检查了页级配色和帧时。源码确认原点以 512 米对齐，两个材质的 8 米与 128 米格点都整除。矿体中心离所属区域边界至少 32 米，最长半径为 26 米。海岸飞行复测重用 1,539 个视图且未淘汰视图，暂维持原池容量。独立 GPU 时间在本次测量口径中缺失，洞穴峰值的归因仍待更细剖析。

## 复现

```powershell
$review = '.local/research/world-expansion-2026-11-22'
unity test . --mode PlayMode --output "$review/verified-playmode.xml" --non-interactive
unity build . --target StandaloneWindows64 --execute-method Reol2.Editor.ContinentAuthoring.BuildLargeWorld --output Builds/WorldExpansion/Reol2World.exe --allow-dirty-build --non-interactive
$player = Start-Process -FilePath 'Builds/WorldExpansion/Reol2World.exe' -WorkingDirectory (Get-Location).Path -ArgumentList @('-continent-benchmark','-world-expansion-check','-screen-width','1600','-screen-height','900','-screen-fullscreen','0','-logFile',"$review/verified-preview.log",'-continent-image',"$review/verified-preview.png") -WindowStyle Hidden -PassThru -Wait
$player.ExitCode
```

`-world-expansion-check` 固定机位及天气来截取角色动作、雨雪、白天、黄昏和夜间，也检查海水和高山。`-world-seam-check` 捕捉洞口扫视及洞内位移，追加 `-world-seed 14376` 可换种子。`-world-long-run` 运行逐帧航线并追加千公里高空与 64 公里贴地。性能基准量总帧时、流送和脚部 IK 脚本，记录覆盖、峰值页数、视图、三角形与内存。
