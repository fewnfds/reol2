# M4–M6 · 世界自行变化，角色可以换一段人生

在同一存档里建立两处可以实际造访的聚落。不论玩家在哪里，他们都遵循同一套物资、路况和组织规则。玩家能从回访中看出谁改变了什么。用可重复的小世界证明这点，再增加地理规模和历史跨度。

## W0 · 先验证两地因果

N8 结束后，先用纯数据建立 2 个站点、2 条路和 1 位运货者。复用 N2 已明确的搬运与收货条件，加可对照的库存和收支。封路信号先由试验输入，收到它的部位等到 W2 才接到真实地形。继任、迁居和动态报价有自己的 H 任务。

可用的试算窗口为 3 个结算日，每天最多一趟货。每批收入 8，接单前预留本次需要的运营支出 6，另加短路运费 1 或备路运费 5。成功交付后收入到账。矿石和货款放在实际站点、携带者与付款方，运输及开支有账目。基础余额取 12，宽裕对照取 20。预期三局交付次数及期末余额分别为修路的 3 次与 15、断路的 1 次与 9、储备充足仍断路的 3 次与 11。第 4 日冲击解除，允许观察恢复。数值可以在 W0 审核时调整。

- [ ] 相同种子与输入可重演。只改“修复主路”这条输入，三个结算日内能看到到货和余额差异。
- [ ] 余额不足时只会推迟或拒绝承担开支。已有货物始终有明确去向，收入对应实际交付。
- [ ] 储备充足的对照可以在同样断路期内维持运输并等到主路恢复。若三局不能用共享结算解释，先修账目与线路，再提高地图复杂度。

W0 通过后推进 M4。W4 的规则可在两处小场景中单独验证，W7 再接入已通过测试的[连续大陆](world-engine.md)。

## M4 · 两地运转与离屏交接

**玩家结果。** 见到一趟货从甲地出发，自己去别处游历，到乙地时可以查到这趟货实际在路上、已到或确因道路中断而暂停。玩家途中修改道路，也会改变相应的人和货。

| 小目标 | 前置及改动范围 | 可验收结果 |
| --- | --- | --- |
| **W1　两处聚落与运输预设** | W0。两座站点用各自的仓、人物与可走入口锚点。给甲两条到乙的道路，主路短，侧路有额外成本。可先用显式场景切换，沿用小数据试验的规则。 | 从任何一边进场能找到入口与站点。纯规则能安排同一份 3 个单位的货物与到期时刻。 |
| **W2　可验证的路段摘要** | W1、N5。先登记道路与地形影响范围，标出路段的可用、阻断、待查及检查时间。路段通行能力先以同一个角色体型为准。 | 挖断一段有影响的路，即便离场也得到暂停或绕路。随手挖无关的山石不会改变商路。 |
| **W3　远区按时间推进行程** | W1、W2。运输起点、货物、人物、路段、进度和到达都用稳定 ID。按时间推进离屏行程，用同一交接规则。 | 远区不在等待渲染，预计时刻能观察到物资变化。封路后商队会等在合理一侧。 |
| **W4　交接同一个人** | W3、N7。近处代理把最后合法位置和阶段提交给记录，交出推进权。返回时在检查过的位置恢复同一人及货物。 | 场景先用显式切换重现；T5 可用时再测连续边界。来回、同时保存与加载、准备出发和临到站都不会重复出现人物或扣货。 |
| **W5　最低限度的世界信息** | W3、W4。用带来源和时间的路况记录，同时供角色决策和可见消息使用。先做一类消息，如主路中断。执行动作仍核对现实条件。 | 乙地居民没收到信时可以按旧路况筹划，不能穿过已破坏的通路。目击或消息到达后改变选择。玩家到乙地只获得当地能知道的内容。 |
| **W6　首个双地回访** | W4、W5。比较“正常运输”“随时前往”“路中封堵并读档”“修复后再回去”四种序列。 | 货量守恒、工作阶段、人物唯一、结算时刻与道路证据一致。测队列年龄、切换动作与场景加载时间。 |
| **W7　连续旅行与两地演算的合并验证** | T7、W6。在连续地图上走同一趟商路。选一段早已验证的预置修路，在离屏结算写入地形编辑与路况，再等待载入重建碰撞。 | 货在玩家回场前就能走新路并结算。回场的世界和账一致。用 3×3×1 活动窗口、4 名近处居民、1 趟跨区运单和接缝挖填，验证默认步速无加载拦停，记录帧时、碰撞就绪时间、队列和分配。 |

**扩张判断。** 先验证一队一货，再增到多条同时行程。局部路的多体型、复杂施工及自动世界级路网由此扩张。W6 通过后可以推进组织变化，W7 通过后再叠加高速飞行、更多路网和世界生成。

## M5 · 组织兴衰与一次真正的时代冲击

**玩家结果。** 一次实用的地形干预让两地成本和人物选择不同。再次回来时，困境或繁荣可能表现为不同的货价、经营状态、主事人、缴费点和旗帜。一个组织能失去地盘，后来有人组织新的据点。

| 小目标 | 前置及改动范围 | 可验收结果 |
| --- | --- | --- |
| **H1　收支与缓冲库存** | W3。先做矿、粮两项库存与一条每日流。首轮用受限的收支、少数生产率与按日消费。 | 短期停运由库存缓冲，持续缺货导致工序改变。每项流入、流出有来源、量与时间。 |
| **H2　最低限度的买卖与服务** | H1。两地价格从库存与供求计算，在交易时确认有货、有钱、容量可用。客栈或工坊挂一个真实提供的服务。 | 主路被修或被截后，玩家能比较同一商品的价格、等待和服务。库存和货币从同一结算更新。 |
| **H3　任职、替补与权限** | H1。组织和个人有独立 ID。小组织先配 1 个关键岗位和 2 名有条件的候选人。代表谁能授权路务、拨款或改服务。 | 旧任离开或死亡后，合格人接手并在现场可见；没有候选时出现空缺，有人来时才补位。一次时刻最多有一个有效任职。 |
| **H4　成立、迁居、退出** | H2、H3。若缺粮、欠账或压力持续，成员依据资源与机会选择留或迁。达到人员、资金与立足地条件时可以建立新组织。 | 原来的人和物去了实际存在的地方。解散会结算剩余物资或留下可找的物资和遗产。小组能成立或维持，世界还可能演化出稳定局。 |
| **H5　一次随机冲击** | H1–H4。先挑一个可廉价检验的地区冲击。预设可重演，普通局按独立随机流与世界状态决定何时何地出现。可先用停产一季或危险带扩大来检验传播。 | 同一冲击传到债务、价格、岗位的实际规则，不同初始库存会缓冲或放大。同种子重演，另一种子允许一个事件都不发生。 |
| **H6　可见的历史** | H3–H5。为公开的继任、关闭、重开、迁居与冲击生成短历史。更换在位者、告示、旗、路口收费、可用服务和废址状态。 | 读几条短记载能找到对应位置或人物。至少两个主体的见闻可因查到的资料不同而不同。 |
| **H7　组织改变路线** | H3–H6。在已有道路与据点上，让有权限的组织分配维修、设置价格、或改变服务职责。施工可先触发预定义体素修改。离屏时使用 W7 所验证的模式。 | 玩家回到旧地时能走到新的修路位置，解释是谁付出资源和劳动。没有条件时工程等待。 |
| **H8　固定种子的因果对照** | H7。共同初值、同一冲击下比较修路与未修。再做库存充足的反例，以及一组改用有实物来源的补给或补贴。 | 不同干预沿共同账目产生可解释结果。开发者在正常回访中尝试从现场与消息推断原因，之后对照真值并记录易误判处。 |

**扩张判断。** 确认因果在有限时间内可观察，再尝试多个组织、地区或不同性质的冲击。灵气爆发可从增加部分生产/修行上限入手，末法从产出和行为机会改变入手，天魔从一支可局部扩散的敌对威胁和真实损失入手。大面积地形与战斗影响等 M8 性能予以支持后再接上。时代效果用少量关键参数与场景差异逐一扩展，也允许世界经过一段平常日子。

### 一对可复验的样本

用一张小地图，将甲工坊与乙驿站以两条路连接。按相同初值运行，设甲基本产矿、乙消耗且需要一段供粮。为验收预设两地一起经历一季产量减少。每一组记起始库存、长短路的费用和货流、组织的计划和已支付账目。

- **A 允许主路绕开风险。** 玩家提前修好一处可用路。商队抵达，甲能支付维护费，乙保持对应商品的供应。经营者可以优先处理别的短缺。
- **B 保持断路。** 货物转走长路或推迟。初始储备充足时能熬到下一季，储备薄的对照会压缩服务，可能让有意愿的人搬往乙地。预设允许观察接班或成立新商组，是否发生由规则条件决定。
- **核对链条。** 变化必须经过已经查到的路况、实收货与成本、人员选择，再体现在职位、服务和环境。用一个保留足够库存的反例验证“封路且不改旗”也能出现。

## M6 · 同一世界内换人、推进年代

**玩家结果。** 角色死亡时世界仍在。可以在仍有合适角色的情况下接手另一个生命，或推进一段时间后从世界真实存在的角色选择。回来能见到前世开过的洞、经历过的人、以及后来发生的变化。

| 小目标 | 前置及改动范围 | 可验收结果 |
| --- | --- | --- |
| **L1　一次死亡，主体结束行动** | W4、H3。提交死亡，释放原角色控制与占用，处理未交付工作及携带物。保存支持当前无人受玩家控制。 | 分别测试先交付与先死亡，再对同一逻辑时刻测选定的优先级。已实收仍实收，尚未交付的货按规则留在死者或地面、转交。 |
| **L2　同刻接手世界中已有的人** | L1、W5。把控制权交给合格的已有角色，从同一世界读取其身体、物品、关系和知识。进场使用经过验证的锚点。 | 新人有自己实际的起始情况，身在远方且未收到消息时不会自动继承旧角色的见闻。上一个人生的地形和历史仍在，同刻只有一个角色接受玩家输入。 |
| **L3　极端随机也能继续** | H5、L2。用能产生致命结果的种子走通波及对象、死亡和历史，接一个按空间范围影响人的陨石样本。跨未加载地区的版本在 W7 后验证。 | 同一事件落在角色处、走远后落在空地与幸存情况可分别验出。自由局开局具备真实发生可能，固定种子便于追溯。“本局并未发生”也是正常结果。 |
| **L4　小时间步对照快进** | H8、L2。空世界视图下驱动已实现的规则，按日或跳到下一事件。先推进一季，并允许在完成的检查点取消。 | 对比逐日、一口气快进与中途保存再继续。核对库存、人物生死、工作、角色知道的变化与历史。进入的地区呈现这次结果。 |
| **L5　可选的多年演进** | L4。加最小的年龄、迁移与成年候选规则，扩大到一年与二十年实验。保证候选是世界已有的可扮演记录。 | 用数个种子测试，没有人可接手时能继续查看或按界面给的选项处理。快进失败回到上一个完整检查点。记录耗时与候选分布。 |
| **L6　归乡与来世试玩** | L3、L4、H6。提供死亡、立即续生、短期等待、新角色入场并回到旧地点的一条完整操作链。L5 通过后再接多年选项。 | 回访者可以在路、服务、人物和公告上辨认前世积累的影响。读档后只见一份当前世界。开发者用正常界面能复述这次开局或回访发生了什么。 |

对无合格候选的处境，候选设计是允许观察并继续世界到下一次可选机会，或供玩家保留这份存档并选择别的地区或规则可达的身份。开局绝对保护、强制重开与复活次数上限都需要单独确定。测试先覆盖无候选时安全返回和不篡改旧档，以便择一试玩。

L6 加一条重开检查。首日致死且暂时没有合格候选时，保存退出。再进是同一世界和保存时刻，死亡、落物、地形和其他在途活动可查。从无人受控界面继续观察或等待合法候选。

**扩张判断。** 一季快进至少和逐日推进在关键结果上匹配才测多年。新一局在开局随机死亡、回到旧地或多次连续重开时都应能读懂发生了什么。若没有时间推进需要的规则，先把立即续生做扎实，进一步推演亡者去向和候选生成。 [下一阶段](expansion.md)
