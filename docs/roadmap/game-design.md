# 游戏设计与大胆构想

规划草案 · 2026 年 11 月 21 日。平台暂为 Windows 单机。目标玩家首先是开发者本人，判断标准是一段世界变迁是否值得他亲自回来看看。类型以自治世界模拟为主，用第三人称动作与体素改造承载玩家的体验。

## 玩家在世界中做什么

> 玩家作为任意有灵万物，在一个动态变化的沙盒仙侠世界中，通过探索与变强，获得角色扮演体验。

开发方向来自用户访谈。原话给出了世界范围和想要的体验，下面的地点、人物、数值和首批玩法是用来验证它的提案。[设计方向草案](../design-direction.md) · [原访谈所在对话](codex://threads/01a1f994-e332-7ae1-a7a4-865e2c1385bd)

| 支柱 | 玩家会发现什么 | 缩到第一版怎么验 |
| --- | --- | --- |
| **世界靠自己的规则继续。** | NPC 用自己掌握的消息做决定，组织有继任、扩张、分裂和衰落，某地会在玩家离开时变化。 | 在同一据点离开和回访，比较人、货和服务。换种子会有不同变迁，固定种子能复验因果。 |
| **动手改变地形会改变别人能做的事。** | 挖开的洞、修好的路、被破坏的桥都会影响实际走法，从而改变送货、定居、巡逻和贸易。 | 挖断矿路使正在工作的人改道或等候。填回去后，该人接着完成同一份工作。 |
| **身份带来不同的行动与责任。** | 一个生命所处的位置、身体、知识和权限决定它此刻能做什么。同一个时代可以用开店、修行、管理门派或作为飞鸟等方式体验。 | 面对道路中断，经营者能重配库存与采购，散修能寻找并开辟通路，两者有不同的输入、代价与反馈。 |
| **世界会记得一段人生。** | 玩家改的路、欠下的债、影响的人与组织可能比角色活得更久。新人生能遇到旧事留下的好处和麻烦。 | 角色死亡或换人生后，世界时钟和历史延续。新角色读到自己有途径知道的旧事。 |

### 五分钟、一次回访、一段人生

- **眼前几分钟。** 看眼前地形、人和告示，选一个现在能做的事。走坡、挖路、捡取、交易、练习或执行一个小工序。动作发出的反馈说明身体、物资、地形与关系发生了什么。
- **几天到一季。** 选择哪里住、如何谋生、跟谁合作、怎样变强。路线、库存、岗位、灵气和当前局势改变机会，玩家可以随时出门看别处。
- **数季到数年。** 游历之后回访熟悉的人和地方。可看地标差异，在市集观察价格和迁居者，也可翻自己记下的线索。返回时的变化可以乐见、冷漠、敌对或与玩家无关。
- **一段或多段人生。** 经营一家客栈、成为体面的门人、找到自己的修行方式，或只在路上观察。角色失去行动能力后，以同一世界的另一个身份重新进入。死亡、时间跳跃、承接线索与困难模式的具体选项在 M6 试玩决定。没有必须完成的主线胜利条件。

随机事件可以在开局就波及玩家，包括罕见的致命结果。事件是否发生、在哪里、谁受到影响都由规则与随机性决定。开发预设用于重复验收；自由开局能否通过提示、声音或事后记录读懂生死，是要试玩的问题。开局无敌、强行拯救玩家和每局定时灾难都属于会改变用户所求体验的策划决定。

## 一个贯穿开发的世界样本

### 小小一条路

山坳有矿点、工坊和两条能走的路。工人需要在约定时间领工具、取货、送货。雨后塌方或玩家挖掉支撑，主路变得不可走。工人有可行的侧路就绕，找不到就保留货物并回报受阻。玩家可以修回原路、开一条成本更低的新通道、为自己的交易设法绕开矿点，或旁观。工坊实际缺货时，某些服务慢下来或要价更高。这条链先由脚本测试操作注入来复验，再放到自由场景真实挖填。

### 二十年后的村镇

下列是对照实验走向，用于把愿景拆成机制。两组可以共用同一初始世界和驱动外部冲击的随机种子。

1. **第一年。** 当地靠粮食和灵矿互换。玩家是客栈帮工，每天接待商队、为厨房买粮。一次灵潮改变山中资源产出，商队改走较高的古道。旧门派的守路人病故，职位空缺。
2. **路径 A 有干预。** 玩家修复低处坡面，让车辆能经过，再请村里的工队维护。运费下降，工坊稳定交货，村镇用账面盈余雇接班人。后来商队和宗门分税并争夺管理权。玩家可转成散修，承接巡路、通过飞行侦察阻断位置，也可经过时只看一眼。
3. **路径 B 无干预。** 小村成本上升，客栈暂停供餐。经营者把家人迁到古道另一端，与商队合办新市集。旧组织持续缺人、缺收入，交出据点或自行解散。粮、矿的价格与库存一起变动，当地招工和租住也改变。
4. **二十年后。** 作为村里长成的学徒、外地散修或一只沿谷迁徙的灵兽回来。A 的路旁有修过多次的石面和征税牌，更容易找到老师。B 的旧客栈多半空置，原店主或继承人住在新聚落，原来的矿点可以重新开采。可见结果由站点的库存、道路、占地、职务及居民记录导出。
5. **随机分歧。** 陨石可能直接摧毁其中一个站点，也可能落到无人山地；灵气枯竭可能让曾经依赖法术维持的产业失效。世界会用生产、迁移、争夺和修复继续演算。通过改变一个输入或撤掉一次干预，能对照哪些结果是因果、哪些来自随机抽样。

这个样本不需要每一个居民二十年间每秒活动，也不需要手写两支剧情。早期用有库存的站点、路线成本、继任候选、事件影响与历史记载取得两组可观察结果。真实玩法中允许出现别的结果。

## 系统与玩法全景

| 玩法 | 玩家真正能做的事 | 第一份能玩的内容 | 可逐步扩张 |
| --- | --- | --- | --- |
| 探索、居住、建造 | 发现洞口、维修坡面、开口绕行、放设施和标记定居点。 | 两块曲面上挖建，走一段可维护道路。 | 屋、桥、灵田、地道、法阵、地下聚落，逐一对通行与服务有用途。 |
| 人的日常、生产与库存 | 本人劳动、与居民交易、接手工作、安排岗位。 | 取 3 份矿并送入工坊，工人和玩家走同一实际地形。 | 粮、矿、工具，再到作物加工、设备维护、运输契约。 |
| 市集、客栈、农户 | 决定买卖、订货、库存和可提供服务；经营者能决定是否聘人。 | 一处进货、一次交付和一项服务有成本。 | 食宿、雇工、农时、客流、租约、加工与地区差异。 |
| 关系、知识、传承 | 亲眼发现、向人求证、学会一种能力、传人或留下记载。 | 告示记录矿路和主事人，离场消息保留时间。 | 口耳传播、误传、家族传承、师门课程、功法和图纸流动。 |
| 修行与探索成长 | 积累资源、练功、请教、突破，打开行动空间。 | 一项能力为“抵达另一处”或“修复一道地形”服务。 | 灵脉、材料、传承和境界的确实差异，失去修为、改学和相克都依试玩决定。 |
| 组织与统治 | 受雇、领职责、交割物资、任命、分配配额与维护。 | 小工坊或据点的主事人与矿路维护岗位。 | 门派弟子、执事、掌门和城邦统治，以权限、账与人手逐步扩展。领土与外交后置在此链上。 |
| 生命、生态、时代 | 观察迁徙与缺粮，亲历灵潮、灾害、冲突，换身份继续。 | 两地、有限库存、一次人员变更和一项冲击。 | 年龄与继承、组织建立和覆灭、地区战争、天魔、末法与灵气复苏。 |
| 战斗和飞行 | 第三人称地面动作、施法、空中航行、逃离或改造场地。 | 独立练习场有一个对手和一项范围可控的地形能力。 | 自由瞄准与辅助锁定、怪物与空战、小规模修士冲突。 |
| 角色与身体 | 不同身体获得不同的移动、感知、行动时间尺度。 | 两种人类活法，再试一种飞禽或地面灵兽。 | 草木、群体或定居型生命，有自身的可玩循环和对环境的影响。 |

### 先用同一件事分出角色差异

| 身份 | 路被堵时可以做什么 | 进步反馈 |
| --- | --- | --- |
| **农户或客栈经营者** | 把种子、粮、餐位、售价或采购改到可用时段，与人谈替代供给。 | 有盈余能储粮、雇人、换位置，村民对店铺的使用随服务变化。 |
| **四处游历的散修** | 用机动性寻找物资和消息，为自己或别人开路；用时间、灵力和风险换机会。 | 学到能改变到达、战斗或采集方式的技能，进入曾经到不了的地方。 |
| **门派杂役、执事或掌门** | 杂役执行一项工序并报告约束，执事能调人和材料，掌门承担多部门的政策后果。 | 职责、信任、权限和组织收支提供分层后果。 |
| **灵兽、飞禽或草木** | 飞禽找安全落脚地或在上空发现信息；草木选择生长方向、积攒灵气或与来访者交换庇护，在较长时段演进。 | 观察、旅行或经营自己的地盘有不同的代价。先让一个非人身份在同一事件中出现有效选择，再加下一种。 |

角色的世界地位影响能做什么。玩家可以通过日常行动自然接触宏观系统，也可以自愿承担管理。信息先从见闻、消息和时间戳做起，组织地图只是读得懂的可选视图。测试和调试可以有真值视图，正常游玩见到的内容以角色可获得信息为准。

### 补齐氛围与世界设定

- 先定义 2–3 个能改变物资、身份或地形的设定。可借灵气的浓淡解释修行在地域的差异，用官道和山门解释通行与税，用时代纪年记录玩家跨多段人生看到的变化。世系、历法、物产和组织用小样本随着切片补齐。
- 首批环境用低多边形体型、简单材质和统一色域。角色用少量可复用骨骼、衣服、颜色、携带道具和动作区分身份。暖色灯、路牌、地标、阴影和声音负责告诉玩家可走路线和角色工作状态。按格编辑与连续坡面都能看明白。
- 内容制作优先程序几何、同一供应来源的免费模型、CC0 或明确允许的素材。AI 模型资产和开源参考同样记来源、版本与许可。先保证视觉一致、碰撞合理、骨骼/导入能复用，再提高精度。[资产来源与许可约定](../development.md)
- 音频先配脚步材质、挖/填、阻断、交付、昼夜风声和事件提示。音乐、语音、字幕完整制作按可玩版本的缺口推进。键鼠先做好可调灵敏度、重绑和关键反馈可见，手柄、镜头舒适选项在动作切片中核验。

## 激进候选及低成本试法

| 候选 | 最便宜的可玩版本 | 共用的机制 | 决定是否升级的证据 |
| --- | --- | --- | --- |
| **地形实际上有政治重量。** | 玩家挖毁唯一能运货的坡，并公开选择修复或开新路，涨价与迁移发生在另一地。 | 地形编辑、局部通行、路权、库存、贸易。 | 玩家能从脚下的路推断远处变化，地图又允许新的路径。若只能由人工触发脚本认出地貌，先加有限路段映射。 |
| **世界可以繁荣也可以走向衰败。** | 一种灵气变化真的改变资源再生与少数法术。曾经靠灵脉赚钱的组织迁移、停业或分裂。 | 灵气量、产出投入、选择、地区交通、人员损耗与继任。 | 两个种子在同一规则下形成不同的幸存中心，商铺和环境也呈现差异。若只看到日历触发换色，停在一地可读后果。 |
| **一块石头改变一生，世界接着走。** | 一次概率与位置抽样决定小型陨石，波及人和通路；留下坑、死者与一条可辨的消息，接到下一段人生。 | 灾害调度、行动后果、地形编辑、伤亡、新控制者和历史。 | 首日也能触发且事后能核对因果。要继续做更大袭击，先测玩家是否觉得跨人生的世界值得继续。 |
| **玩家的旧生活成了他人的传说。** | 一座桥保留它的建造者和维护者，新身份从路牌或老居民得知，沿改造后的路走过。 | 结构 ID、维护、历史、知识和消息。 | 地标、角色记闻、功能状态互相对得上。先用短模板和真实引用，长文本在确有需要时增加。 |
| **极端身份有不同的时间感。** | 一只飞鸟靠换栖点和观测路况活下去，或一株灵树靠点选生长和交换，让周围据点来找它。 | 身体、能力、感知、资源、驻地、时间快进。 | 任务要求只有这种身体才能以独特办法完成。判定“可玩”靠有意思的取舍，角色外观可以先非常简单。 |
| **修行可以改写地理。** | 一个范围明确的地形法术改变一段路或打开洞室，居民因此改用路线。 | 能力执行、地形编辑队列、通行与经济。 | 观察角色动作是否连贯、结果是否可预期及破坏速度是否值得牺牲细节。 |

## 现阶段的取舍

首个可回访版本先做地方小史、交易、人物更替和一件随机冲击。完整主线、国与国战争、成百种生物身份、大型战斗、真实流体与结构坍塌都保留为扩张方向。它们进入实现时各有独立的可玩切片和容量测试。内容数量、开放世界的实际尺寸、是否有锁定或空战、以及具体进阶体系由后续可玩结果决定。
