## 执行前看到的事实

- **开发者的原始方向。** 回看最初访谈确认，无缝行走和飞行、附近地图动态加载、远距传送可读条，世界可以像策略游戏一样演变，玩家以一个生命的处境参与。接受统一的低成本美术，不再追求万人同屏。死亡可以发生在非常早的时候，新人生延续同一个世界。剧情是后期方向，最早先看体素修改、角色移动与世界框架。[原访谈所在对话](codex://threads/01a1f994-e332-7ae1-a7a4-865e2c1385bd) · [当前游戏简报](../preproduction/brief-reol2-2026-11-21/brief.md)
- **Unity 源码。** 当前基线提交为 `a7bfbfd`。`DensityVolume.Edit` 有序写入共享采样，填土来源索引依赖有限密度域。`VoxelDemoTerrain.Rebuild` 准备渲染和碰撞后切换，角色用现有碰撞行走。M1 和 M2 的建议直接用这些入口。[密度场](../../Assets/Reol2/Voxels/DensityVolume.cs) · [场景地形](../../Assets/Reol2/Demo/VoxelDemoTerrain.cs)
- **现有验证。** 沿用已留存的 5 项 Play Mode 通过报告和 Windows 双块开发构建的离屏测量。最近该组 100 次编辑测到 7.458 ms 编辑帧 P99、1.728 ms 编辑到碰撞 P99 和 0 B 主线程托管分配。较早另一轮结果见原型页。地区规模、快速飞行、NPC 数和多年推进仍需要各自的基准。[现有测试](../../Assets/Reol2/Tests/PlayMode/VoxelDemoTests.cs) · [原型测量](../prototype.md)
- **规划方式。** 以 BMad GDS 的设计支柱、循环和史料分层梳理体验，用 writing-plans 的可测任务方法展开近期实现。以原型和实际类的入口给新执行者开工点。完成小切片后用已有游戏规则和小数据继续验证。

## 双顾问交流

Web 初次尝试返回账号需恢复认证的 `503`。等待时用已保留的 AI Studio 并行完成前两题的四份补充意见。用户重新配置 Web 后，实际回到默认的 `gemini-4-neon` High 与 `gemini-4-neon-task`。两模型每次收到同一份冻结输入。咨询的请求、完整答复和状态记录在本机 `.local/research/roadmap-2026-11-21/`。

| 轮次 | 问题和输入 | 取舍与跟进 |
| --- | --- | --- |
| **1　大胆发散**，`01-vision-web` | 设计方向、Demo、二十年对照、身份与因果。 | 两路均从同一条路推到粮价和组织兴衰。采纳一道便宜的可观察后果、固定对照样本和非人独特动作。河流物理、大规模崩塌、极短的硬性能门槛作为后续试验。 |
| **2　技术推演**，`02-system-web` | 几个相关 C# 文件，持久化、同尺度及近远交接。 | 确认有序编辑、halo、角色知识和实物交接是主要接缝。先用一致手动档与现有密度域。每次写盘日志、提前拆块、量化压实都要实测收益。 |
| **3　追问替代路线**，`03-tradeoffs-web` | 把前两轮建议与取舍交回，考察小数据反事实、死后结算、时序和阶段先后。 | 两路都指出完整流式会把关键因果验证压得太晚，加入 W0 并让 M3/M4 独立交付实验结果。W5 提前验证见闻，L1–L5 明确死亡与交付边界，并纳入快进途中存读对照。 |
| **4　交叉审查完整草稿**，`04-final-review-web` | 七篇规划草稿，走查第一轮存读、任务依赖和失败风险。 | 给首个档位定边界、保留独立 Demo。W0 缩到有限结算期，W7 测步行装卸、地形编辑和居民协同。W5 让角色根据旧消息行动。区域生成分为宏观锚点和可通行地形。 |

四轮 Web 咨询共八份完整正文。记录显示各轮普通 Neon 为约 153、126、138、216 秒，Task 为约 85、109、100、150 秒。AI Studio 补充意见用于对看意见分歧，技术取舍以当前源码和实验要求为准。

独立走查增加了已发布变化范围与修订、第二块网格准备失败、正常步行和离屏维修，以及零候选死亡后保存重开的用例。

### 有争议的工程假设

- **放置来源。** 两位顾问识别出双块原型的 `fillSource` 线性数组索引。大陆采用按全局位置解释的来源，存档用例验证重新选格。
- **顺序敏感的挖填。** 相邻格共享采样，挖填顺序会影响最终样本。验收保留真实的接缝、凸出土块选取和碰撞。早期两块 Demo 的整份动作回放已由大陆精确页覆盖方案接替。[存储与验证](voxel-storage.md)
- **任务暂停、失效和重算。** 暂停保留真实货和工作。重新安排路线时先看已经发布的碰撞或已验证路况。远处可粗略计时，重复结算由同一工作状态约束。
- **保存与演算速度。** 各模型给出的毫秒阈值和 20 年耗时估算跨度大，测量场景也不同。采纳要测的变量、反例及不变量。阶段验收的具体性能预算以新的 Windows 与纯规则实验为准。
- **戏剧性。** 顾问想象里的组织易主、地景崩塌或死后短镜头都是演示样例。完整重演关注物资、人物、路径和已知信息。平稳存档、倒霉开局和自愿不干预都是能接受的不同结果。
