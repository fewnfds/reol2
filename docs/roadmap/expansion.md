# M7–M9 · 不同身份、自由动作和大世界

让这些系统接在 M6 的可玩世界上。每种加入的角色、技能、商品与地区都应给现有世界增加一种决策或反馈。长远目标允许为任意有灵之物设计活法，可以从一名农户、一个散修与一种非人身体起步。M7、M8 可按试玩需要并行做独立验证。

## M7 · 身份真的有不同的活法

**玩家结果。** 在同一地区遇到供给不足和道路中断，凡人经营者能安排进货、库存和营业，散修能搜寻、穿越和改路，组织执事依据岗位指派资源与工作。先证实两条有趣的局部循环，再追加任意身份。

| 小目标 | 改动范围 | 可验收结果 |
| --- | --- | --- |
| **R1　从世界状态建立出身** | L2。选择两种人类起步身份，每种给具体住处、身体、资源、关系与在时钟上的义务。数据带稳定 ID。 | 两个出身从真实状态读入。缺工具、没有权限或不了解消息会改变当前可行动项。 |
| **R2　经营一项能被需要的服务** | H2、R1。一间小客栈先做进货、库存、售餐或住宿其中一项，引入需要按时间来的人。一天可见进项、消耗与收益。 | 停供、限价或多买一批货会改变客流或结算。读档不重复放出货、钱和服务名额。 |
| **R3　农户的一季** | R2。在同一套库存和时间基础上加入少量耕地、种子、施作与收成。气候和灵气可先用小参数变化。 | 农户用等待、劳力与风险换来可售物资，应季缺粮影响客栈或邻地。玩家有可主动选择的日程。 |
| **R4　散修的一程** | R1、H7。从两地探索、一次闭环的学习或修行、一个改变到达/通路的技能开始。考虑老师、传承和练成的条件。 | 练成技能之前与之后，同一障碍有不同代价或可行路径。散修的主要操作可独立于经营界面。 |
| **R5　从杂役到管理岗位** | H3、H7、R1。岗位指定少量工位或辖区、预算与工作权限。小组织的执事学习分配两项具体工作。 | 杂役能执行和报告，执事能调配，接班后的有效权限来自组织。越权请求保留之前账目。 |
| **R6　把知识和关系带进决策** | W5、R4、R5。传递两种具体内容，例如断路消息与可学习能力。记录取得方式和时间，支持忘记或过期的体验实验。 | 角色根据已知选择去向。事实变了以后可能按旧消息来，在目击或收到新消息后调整。 |
| **R7　一种能玩的非人身体** | R1、R6。选灵兽、飞禽或草木之一。为其定义能力、空间和行动时段，复用移动/通路和位置记录。飞禽先依赖 A3 的可控飞行。 | 有独特的资源和操作。例如岩兽可嗅探、掘洞，难以经营人类的店；灵树可选择生长和等待。两种身体到达同一情境时显出差异。 |
| **R8　测试身份的实际区别** | R2、R4、R5。用同一初始世界配不同角色，比较它们遇到一项危机时能看到什么、如何处理、有何收益。 | 至少两个身份可从动作和资源流区分，即使隐藏名字和外观。经营者停供或散修改路实际改变另一身份可用的机会。 |
| **R9　继续扩充人生内容** | R6–R8。按试玩增加工艺、图谱、师徒、家族、装备与身体状态。每项接入已有工作、能力、市场或信息机制。 | 新身份和工艺继续用同一世界，经济与时间不会为它另外启动。权限、身体、资源或操控至少一项出现可见差异。 |

**扩张判断。** 首次做经营与散修的两个人类活法。玩家在熟悉的地图上能分别完成不同的目标后，再选一个非人身份。草木的试玩可先用固定镜头与少量时间决策，飞行动物优先复用已经测过的移动和着陆。掌门与国主分别扩到管理多个部门和统筹区域，一个真实权限要有一处可观察后果。

## M8 · 动作战斗、飞行和高魔破坏

**玩家结果。** 在一个已经能走坡和挖建的场景中，能进行简单的第三人称近战，尝试瞄准施法，短途飞上山脊或安全着陆。可以用战斗能力打开一处洞或破坏正常的通路，让居民和服务反应。

| 小目标 | 改动范围 | 可验收结果 |
| --- | --- | --- |
| **A1　动作练习场** | T7、L1。复用真实玩家控制，挑一个练习对手、一种近战、一次闪避或撤退和一组受击反馈。 | 玩家可用键鼠控制出招、取消范围和退让。击中、落空、失去行动能力有清楚视觉或声音。 |
| **A2　一项远程能力与瞄准试验** | A1。设一个有可读准备、弹道和影响范围的虚构法术。对比自由瞄准与轻量辅助锁定。 | 在目标间距与速度相同的实测里比较命中、镜头舒适、可辨反馈。由开发者试玩选择采用的辅助程度。 |
| **A3　起飞、移动、着陆** | T7、A1。先短程可控飞行。给横移、升降、转向和着陆明确操控与资源取舍。保护载入边界及坡面碰撞。 | 重复在坡地、洞口与活动范围边缘起降。高速碰到未就绪地形可安全减速并继续加载。 |
| **A4　批量地形能力验证** | E2、N5、A2。把有限范围的挖填计划交给同一格编辑入口。先定量、分批、对相关视图一致发布，损耗和作用中阶段可查。 | 能从演员动作到场地变化到 NPC 改路，有时间上可追踪的证据。保存重开后不重复施放已生效的修改。 |
| **A5　飞行碰上场景工作量** | A3、A4、W7。飞线上有人、活动区装卸、编辑和碰撞都可能发生，做可重复压力用例。 | 测到有参与量的帧时、过龄任务、峰值内存与可见接缝。达到安全与体验预算才提高飞行速度或破坏面积。 |
| **A6　一次可参与的冲突** | A4、H5。让少量对手和居民实际在同地活动。加入逃离、协作、直接改变通道等解决方式。 | 玩家能打赢、逃开或从另一条路完成目的，结果影响实际人物、物资和通行。未目击角色只能从适当线索获知。 |
| **A7　决定空战深度** | A2、A3、A5。用一个敌人试飞行中地形遮挡、自由瞄准、移动预判和退场。动画打磨与战斗人数从这个场景推导。 | 玩家可以在不丢目标、不误判落点的前提下完成一次短交锋。开发者试玩后决定做空战、辅助锁定或以飞行为探索。 |

**扩张判断。** 战斗先做好输入、镜头和读招，再加技能。渲染和物理先保玩家周围，高速预取、远景 LOD 与浮动原点分别由 A5 数据验证。大型打斗、阵法攻城和更大的可破坏体积沿着实测人数、搜路量和编辑速率增加。用户已接受同屏规模以性能结果为准。

## M9 · 扩成可长期重复游玩的世界

**玩家结果。** 数个区域因地形、物资、关系和时机形成各自面貌。某局继任平稳，别的局出现迁徙、组织斗争或时代冲击。玩家可以从自己关心的地点开始，在相隔多年后识别真正保留下来的后果。

| 小目标 | 扩张内容 | 可验收结果 |
| --- | --- | --- |
| **G1　形成一组可复用环境素材** | 统一低多边形轮廓、色板、尺度、骨骼、灯光、音效和各类物件的碰撞。保留来源、版本、许可与替换路径。 | 用同组资源能构建两个有区别的据点，每处可从外观认出进出口、道路和主要服务。添加一种角色或道具的耗时可测。 |
| **G2　生成区域锚点与路线候选** | W7、H7。先用小策划模板和种子给有限数量的地区、物产、站点与粗路段。对每个路段保存坡度、通行宽度和入口要求。 | 纯数据能复现同一张候选图，两个预设锚点合理相连。随机分布产生坏候选时可重新生成，现有世界的档仍可读。 |
| **G3　让路线在可玩的地形里成立** | G2、E2.1。初版以已知锚点与基础道路作为地形生成约束，先从简单山谷坡道起。等每种地貌通过再加入洞道和多层通行。 | 抽样加载几个种子的入口与路线。身体可以通过，路况和实际碰撞互相对应。验证有确切的失败位置与种子。 |
| **G4　生态和多样人口** | R7、H5、G3。加入用少量规则解释的季节、栖地、食物、迁移与种群。先把一层动物和一种植物资源接入现有生产与地理。 | 生态随供给和冲击走向不同，远区需求与具象化时的实体数量一致。地区可有恢复与消亡两种结果。 |
| **G5　领地、外交和更大冲突** | H3–H8、A6。权限扩到多个据点，加入少数税、路权、盟约和冲突规则。同一场冲突可影响贸易、驻地和人民迁徙。 | 主人变化在账与世界中均查询得到。和平、分裂、吞并和组织瓦解各有小规模复现。 |
| **G6　逐个加入时代剧变** | G4、G5。先有灵气产出变化，然后做末法、复苏和入侵。每一种定义成因、影响半径、进程、能否终止及残局。 | 几种冲击有不同结果。玩家参与与旁观都能继续。多个冲击叠加会留下有依据的冲突或重建。 |
| **G7　多年档、容量和内容验证** | L5、G3–G6。跑种子样本与长时加速，检查资源、人员、档位大小、回访一致性、加载和近场帧时。 | 抽样的存档能退出重开，坏档有可用备份，性能和稳定性达到本地可接受程度。规模增加后的薄弱点有原始测量。 |
| **G8　主线和手工事件试作** | H6、G6。进入扩展内容时可选择一小段正邪冲突、带后续的委托或天魔故事，让状态决定哪些角色和地点参与。 | 主线能在不同世界条件下进入或自然失效。已有地方历史与人物不会为剧本回滚。 |
| **G9　发布体验与维护节奏** | G1、G7。形成默认开局、操控提示、可读音画、保存管理、迁移政策、Windows 启动说明和版本回归。G8 按选中的内容接入。 | 在干净的 Windows 构建目录按说明开局、退出重开，试玩一个合格切片。记录仍限制地图、角色或战斗规模的证据。 |

**扩张判断。** 有限内容和一致存档先支撑多局可玩。增加一个地区时同时检查旅行、活跃对象、处境差异和运转成本。新主线、动态流体、结构破坏、模组及面向他人的发行均可成为独立决策，有清楚的试玩收益后再立项。

## 开发资源怎么用

- **一轮只加可玩的内容。** 新系统先放在原测试地区，真正在世界中出现后再制作多套内容并复核玩法重复度。
- **道具和行为分别迭代。** 能用几何占位验证时先完成路线。少量一致资产使 NPC、路况和设施容易识别，真实授权和复用说明跟着资产提交。
- **世界规则和表现各自测量。** 日历压力不用开 Unity 窗口，人物感受与渲染则用原本的玩家入口。低配与高魔扩张以各自实测为准。
- **用小测试防回退。** 保留 M0 双区块、M2 矿路、M4 两区交接和 M6 人生回访四类回归；改世界版本时留代表档及预期变化。GitHub 继续使用单作业静态检查，重的验证留在本机对应切片。[验证矩阵](architecture.md#测量矩阵)
