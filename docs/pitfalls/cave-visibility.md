# 洞口和洞内视野

用同一个种子和机位比较碰撞与渲染。沿洞口通道从外向内、再从内向外各取一帧。记录相机高程、天然地表高程、粗洞壁发布量和远裁剪距离。碰撞射线畅通而画面被封住时，检查高度瓦片遮住开口的情况，以及相机的天空盒、雾和远裁剪设置。

恢复天空后，从洞室和弯道再检查岩壁。若有蓝色空洞，先确认粗洞壁网格是否在洞室内部结束。当前 Windows 回归读取两种清屏颜色下的屏幕像素，检查洞口开口和封闭岩壁各自应有的表现，并复跑完整穿洞路线。[Windows 回归命令](../large-world-demo.md#复现)

排查线状透光时，可以用纯色清屏，并固定相机和世界坐标分别显示高度瓦片、洞口网格、粗洞壁和近场页。检查空隙附近的世界坐标是否落在洞壁覆盖边界或瓦片边界。比较近远景时只移动流送中心，记录轮廓变化，再用角色落脚和 MeshCollider 检查可达表面。[近远交接](../roadmap/world-engine.md#近远交接)
