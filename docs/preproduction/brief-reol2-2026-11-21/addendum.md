# 原始输入摘录

## 已知方向

- 目标平台当前为 Windows 单机，项目使用 Unity 6.3 LTS、URP 和 C#。
- 用户希望探索庞大的高魔世界，玩家以世界中的一个生命参与其中。
- 长远方向包括附近区域动态加载、远距传送、NPC 自主行动、组织与政权演变、随机时代事件、角色死亡后在同一存档 Reroll、可挖建地形、第三人称动作和可能的飞行。
- 美术接受低精度、风格统一和低成本素材，优先让世界能够被填充和运行。
- 现有文档中的愿景、例子和原型仍可修改，不应自动成为绝对约束。

## 本轮回答中的细节

- 开发者喜欢围观和感受世界变迁，也希望能对它施加影响。典型游玩延续此前的探索、成长、不同身份的生活与对世界的参与。
- 多项玩法方向都重要，先建立世界框架，再按完成成本和试玩结果逐步推进。
- 宏观借鉴《文明》《战锤》，微观借鉴《Kenshi》《Minecraft》和第三人称动作游戏。

## 待验证或后续决定

- 首轮记录区块边界的显示、碰撞、通行和编辑开销。更大的地图、动态加载、存档与远区模拟另设验证场景。
- 后续用具体身份验证游玩差异。首批身份、会改变普通生活的世界事件、内容规模和音频方向均待定。

更多长远想法与例子见[设计方向草案](../../design-direction.md)。
